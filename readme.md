# Ideas

Skater abilities:
	- Dash
	- Sucker punch
	- Board slam
Features:
	- Hits can knock you to the ground
	- Ref that gives penalties for fighting _it sees_
	- Hadouken-esque button combos for moves like michigans, etc.
	- Hold shoot button for snap-shot
Skater types:
	- All rounder
	- Playmaker (good at passing and skating, bad at shooting and fighting)
	- Enforcer (good at fighting, ok at shooting, bad at skating)
	- Sniper (good at skating and shooting, bad at passing and fighting)
	- Caleb (unbeatable at fighting, really really slow / high momentum, good slapshot, literally no ability to pass)
